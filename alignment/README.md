# Alignment

## Build and test

Run from the repository root. Requires CMake 3.28+, a C++17 compiler and Python
development headers; `uv` installs Halide and pybind11.

```bash
uv sync --extra native
cmake -S alignment -B build/alignment \
  -DPython_EXECUTABLE="$PWD/.venv/bin/python" -DCMAKE_BUILD_TYPE=Release
cmake --build build/alignment -j 2
ctest --test-dir build/alignment --output-on-failure
.venv/bin/python -m unittest discover -s alignment -v
```

The build writes the extension into `handheld_super_resolution/`. Rebuild after
changing native sources or switching Python versions. Kernels target the build
machine's CPU (`TARGETS host`); rebuild on the destination machine when moving
between CPUs with different instruction sets.

## Calling from Python

```python
from handheld_super_resolution import alignment

# reference_image and moving_image: 2D grayscale arrays in [0, 1].
options = dict(
    scale_factors=[2, 4, 4],
    tile_sizes=[32, 32, 16, 8],
    search_radii=[1, 3, 4, 4],
    norm=["L1", "L2", "L2", "L2"],
    ica_iterations=3,
)
reference = alignment.build_reference_pyramid(reference_image, **options)
moving = alignment.build_moving_pyramid(moving_image, **options)
flow = alignment.align(reference, moving)
```

Level settings run finest to coarsest. Scale factors are successive downsampling
ratios, so N factors require N+1 tile sizes, radii and norms.

`flow[row, col]` contains `(dx, dy)` in input grayscale pixels: sample the moving
image at reference position `(x + dx, y + dy)`. The output uses 16×16 tiles with
stride 8, regardless of the matching tile sizes. The first tile center is
`(8, 8)`, and the tiles never extend over the image span.

Pyramid properties such as `level.image` and `level.gx` return NumPy copies;
editing them does not change the native pyramid.

## Adding kernel variants

Kernels are compiled ahead of time. Unsupported parameter combinations raise
`ValueError`; there is no JIT fallback. Edit these lists in `CMakeLists.txt` and
rebuild when adding supported configurations:

- `ALIGNMENT_DOWNSAMPLE_SCALES`: downsampling ratios.
- `ALIGNMENT_GRADIENT_TILE_SIZES`: reference gradient accumulation tiles.
- `ALIGNMENT_BM_TILE_SIZES`, `ALIGNMENT_BM_SEARCH_RADII`, `ALIGNMENT_BM_NORMS`:
  block-matching combinations (the Cartesian product).

Keep gradient and block-matching tile lists consistent. The block-matching tile
list also controls ICA and flow-transfer variants; flow transfer additionally
includes the fixed 16×16 output tile size. Dispatch tables are generated by CMake.
